# Security

Taskcue starts coding agents that can edit files and run commands, so we treat its API like a shell. How it is
protected is described in [docs/architecture.md](docs/architecture.md#security).

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private vulnerability reporting on this repository (Security → Report a
vulnerability). We'll reply within a few days.

Issues in Claude Code or Codex themselves belong with their makers: Anthropic and OpenAI each run their own reporting
programs.
